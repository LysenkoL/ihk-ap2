## Вывод

Заниматься уже можно: материала и способов практики достаточно для начала. Сильная сторона — связка русских объяснений, немецких условий, настоящих бланков и локальной практики. Главный следующий шаг — соединить существующие части в надёжный ежедневный процесс: конкретная задача → сохранённая попытка → разбор → повтор → следующий пример.

Приложение пока не полностью выполняет обещание «само подберёт, что делать дальше, и покажет, чему я научилась». Есть подтверждённые разрывы сохранения, очереди ошибок и учебных статусов. Их полезнее исправить до большого расширения банка заданий.

В этой сессии выполнена оценка, продуктовый код не изменялся. Ниже исправления и предложения явно отделены от уже работающих функций.

## Подтверждённые проблемы

### 1. Перенос новых тренажёров может вытеснить работу другого устройства — высокий приоритет

`gen/sync.js:55–61,400–401`: для новых хранилищ применяется поверхностное объединение. Нет специальных обработчиков `ap2:code`, `ap2:normal`, `ap2:opueb`.

Воспроизведение через реальную чистую функцию `GENSYNC.mische`, с искусственными данными:

- компьютер хранит задачу A в `aufgaben`, телефон — более свежую задачу B;
- объединение `ap2:code` оставляет только B;
- аналогично заменяется весь `sz` нормализации и `ops` операторов.

Общий журнал может сохранить ранее записанные результаты, но он не восстанавливает черновики и весь внутренний прогресс тренажёра. Уже существующий механизм обратного отката импорта полезен, но не делает такое объединение правильным.

**Исправление:** объединение по задаче/сценарию/шагу, объединение истории по ID, сохранение двух конфликтующих черновиков, повторный импорт без дублей. Проверить разные задачи на двух устройствах и одновременные изменения одной задачи.

### 2. Галочки критериев относятся ко всему бланку, а не к попытке — высокий приоритет

`gen/azubi.js:1395–1418`: критерии лежат отдельно в `ap2:pruefpunkte:<модуль>`. `neuerVersuch` (`323–337`) архивирует ответы и начинает новую попытку, но критерии туда не входят.

Изолированное воспроизведение: после `neuerVersuch` новые ответы и баллы пусты, прежние галочки `[0,1]` остаются; в архиве попытки критериев нет. При следующей самопроверке это может выглядеть как уже выполненные пункты нового ответа.

**Исправление:** хранить выбранные критерии вместе с конкретной попыткой и снимком рубрики. Новая попытка начинает с пустых отметок, старая сохраняет свои. Существующие данные переносить без удаления и без приписывания неизвестной старой отметки новой попытке.

### 3. Ошибки новых тренажёров отсутствуют в общем повторении — высокий приоритет

`gen/lernstand-wieder.js:5,23` принимает `sql`, `algo`, `praxis`, `lernweg`. Источники `code`, `normal`, `operatoren` не подключены. Они записывают наблюдения в журнал, но не получают соответствующего места в общей очереди.

Изолированная проверка четырёх ошибочных событий SQL/код/нормализация/операторы: сборщик общей очереди вернул только SQL. У операторов есть свой внутренний повтор, но он не объединён с ежедневным.

**Исправление:** единая очередь с условием, собственным ответом, разбором и переходом прямо к нужной задаче. Отдельно учитывать полный результат с помощью: он требует будущей самостоятельной проверки, хотя баллы не потеряны.

### 4. Некоторые результаты выглядят более самостоятельными, чем были — высокий приоритет

**Код:** раскрытие «Что нужно сделать (по-русски)» (`gen/code-trainer.js:283–286`) не отмечает помощь. В `gen/code-daten.js:31–35` это уже пошаговый алгоритм, включая переменную, цикл, условие и `return`. После тестов результат может называться самостоятельным. «Новая попытка» также сбрасывает помощь сразу после просмотра решения, хотя задача остаётся прежней.

**Нормализация:** выбор правильной аномалии из списка и другие шаги с вариантами записываются как `kind: auto` (`gen/normal.js:353`), увеличивая счётчик самостоятельных проверок. Воспроизведение для `kurs/anomalie`: три правильных выбора → `independent:1, recognition:0`. Для операторов аналогичное узнавание уже корректно выделяется отдельно.

**Исправление:** различать перевод слов, перевод условия, подсказку алгоритма и образец. Выбор из вариантов учитывать как узнавание. Повтор знакомого решения без открытой подсказки считать отдельным видом опыта; самостоятельное применение проверять на другом примере.

### 5. Карточка «Сегодня» ставит галочки по факту любой активности — средний приоритет

`gen/heute.js:150–168,271–277`: одно повторение закрывает шаг даже при оставшихся карточках; любой сегодняшний Kurzfrage закрывает «5 вопросов»; один ошибочный запуск нового тренажёра может закрыть «Занятие сделано».

Воспроизведение: одна повторённая карточка и девять оставшихся + факт одного занятия + факт одного вопроса → `3/3`, хотя строка одновременно говорит «Повторить ошибки (9)».

Ошибка в ответе не должна отменять выполненную работу. Но галочка должна означать законченный запланированный объём, а успешность ответа показываться отдельно.

**Исправление:** фиксировать дневной набор, показывать `1 из 5 вопросов`, `1 из 3 повторов`, завершение конкретного занятия. Не менять уже выполненный пункт на новое задание с прежней галочкой. Настройка минут — планируемый бюджет, не доказательство фактически потраченного времени.

### 6. Следующий шаг преимущественно следует списку уроков — средний приоритет

`gen/lernweg.js:7–11`: первая неотмеченная тема имеет приоритет над слабостями уже пройденных. Отметка «разобрано» может быть поставлена без самопроверки; результат 0 из 3 также завершает урок. После всех отметок рекомендация ведёт в общий список практики (`115–118`).

Это подходит для знакомства с курсом, но не заменяет адаптивный план. В «Что тренировать» и тренажёре операторов уже есть полезный подбор по слабостям — его стоит объединить с главным следующим шагом.

**Исправление:** выбирать конкретное действие с коротким объяснением причины. Пример: «Вчера не получилось условие цикла. Сегодня — другой пример на 5 минут». Приоритеты: продолжить короткую незавершённую работу → назначенный повтор → практика слабого навыка → новая тема. Не допускать бесконечного застревания в одном слабом навыке.

### 7. Карточка повторения ещё не подтверждает умение решить — средний приоритет

`gen/wiederholen.js:416–418`: новый ответ при повторении необязателен и не сохраняется; две отметки «Gewusst» в разные дни выводят карточку из повторения. Журнал честно записывает такой результат как самооценку после решения, но отдельного обязательного задания на перенос навыка нет.

**Исправление:** сохранить лёгкое повторение разбора и дополнить его следующим шагом — коротким самостоятельным решением того же навыка на другом примере. Сохранять и этот ответ. Новая ошибка должна заново назначать повтор.

### 8. Копирование между устройствами и восстановление копии требуют разных сценариев

`gen/sync.js:554–555` отвергает файл, созданный тем же устройством. Это мешает восстановить резервную копию после случайного изменения, если идентификатор устройства сохранился. После полного удаления данных сайта идентификатор обычно другой, поэтому это не утверждение о невозможности любого восстановления.

Фото находятся в отдельной IndexedDB и не входят в копию прогресса. Это прямо сообщается рядом с кнопкой и является записанным решением от 10.10, а не скрытым дефектом. Фото привязаны к модулю/подпункту, без ID попытки.

**Исправление/предложение:** разделить «Объединить с другим устройством» и «Восстановить свою копию» с предварительным сохранением текущего состояния. Для фото — отдельный необязательный перенос и привязка к попытке; небольшой обычный экспорт оставить доступным.

## Какой ежедневный процесс нужен

На главной — одна кнопка **«Начать занятие · 20 минут»** и устойчивый список конкретных шагов:

1. Продолжить оставленную задачу, если она есть.
2. Повторить небольшой заранее выбранный набор ошибок.
3. Решить один новый пример слабого навыка.
4. Коротко потренировать язык: формулировка IHK или 5 слов/вопросов.

Для 10 минут сокращать объём, для 40 добавлять часть настоящего бланка. «Сегодня только телефон» может выбирать короткие ответы и чтение; «Есть бумага/компьютер» — код, схемы и длинные задачи. Это предлагаемый режим, сейчас такого переключателя нет.

После занятия показывать: что сделано, где понадобилась помощь, что назначено на повтор и почему. Старые ответы остаются в истории. Автоматическое обновление означает подбор следующего задания из проверенного материала, а не перезапись предыдущей задачи или генерацию непроверенного экзамена.

## Отметки и статистика

### Отметки

Нужны два независимых признака:

- **Состояние работы:** не начинала → черновик → ответ сдан → разбор завершён.
- **Состояние навыка:** разобрано → выполнено с помощью → самостоятельно на знакомом примере → самостоятельно на другом примере → требуется повтор.

Отдельно: ⭐ «Избранное», «Вернуться позже», «Не поняла условие», «Возможно, ошибка в задании», личная заметка. Эти признаки не должны автоматически давать баллы или подтверждать освоение. Маркер текста, который уже есть, решает другую задачу.

Нужен один список «Мои задания» с фильтрами по этим отметкам, теме и источнику. В настоящем бланке — отметка конкретного подпункта, а не только всего экзамена.

### Статистика

Вместо одного процента готовности полезнее показывать:

- сколько разных задач решено, сколько только прочитано;
- самостоятельные попытки, помощь, узнавание и самооценку раздельно;
- последнюю самостоятельную проверку по навыку и число разных примеров;
- актуальные ошибки, их повторное появление, сроки повторения;
- причины: немецкий текст, термин, знания, ход решения, невнимательность, время;
- активность недели и изменение результатов за последние недели;
- покрытие GA1/GA2/WiSo по навыкам с переходом к конкретной практике.

Сейчас `gen/lernstand.js:77,91` считает долю по всем самостоятельным автоматическим событиям. Десять проверок одной задачи могут заметно влиять на неё. Для оценки текущего навыка отдельно нужны уникальные задачи и последние самостоятельные попытки. Историю всех запусков сохранять как историю практики.

Не считать тему освоенной только за чтение, нажатие «знаю» или узнавание правильного варианта. Не давать гарантию сдачи на основании статистики приложения.

## Как заниматься уже сейчас

1. Выбрать одно основное устройство для новых тренажёров до исправления их объединения. Делать локальные экспортные копии; фото при необходимости сохранять отдельно. Не считать текущий импорт того же устройства полноценным восстановлением.
2. Открыть «Мой маршрут», пройти одно короткое занятие, написать свой ответ и выполнить самопроверку. Отметка «разобрано» удобна для учёта прочитанного.
3. В тот же день решить 1–2 задачи по этой теме в SQL/коде/практике. Открывать образец после своей попытки. Не ориентироваться только на зелёный итог.
4. На следующем занятии открыть «Fehler wiederholen». Ошибки новых тренажёров пока дополнительно проверять в них самих.
5. Периодически брать одно задание настоящего GA на бумаге, сверять по критериям, записывать причину затруднения. Полный бланк нужен для тренировки времени, когда короткие задачи стали привычными.

Это позволяет начать подготовку без ожидания всех будущих функций. Полностью автоматический ежедневный маршрут пока требует этапов выше.
