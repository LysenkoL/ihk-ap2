# AP2-тренажёр (ap2-sim)

## Что это

Личный тренажёр к письменной части IHK AP2 Fachinformatiker Anwendungsentwicklung: GA1, GA2 и WiSo. Экзамен 28.04.2027. В приложении есть учебный маршрут, практика и тренажёры: объяснения по-русски, задания по-немецки. Ещё есть плеер оригинальных экзаменов. Это статическое PWA, работает офлайн. Учусь в основном с телефона.

## Правила

- **Мобильный экран первым.** Всё делаем сначала под ширину 390 px: без горизонтального скролла, кнопки удобно нажимать пальцем.
- **Язык.** Интерфейс и объяснения — по-русски. Экзаменационные задания — по-немецки. Немецкие образцы ответов — простыми короткими предложениями, термины с переводом.
- **Технологии.** Статический HTML/CSS/JS без сборки и без новых внешних зависимостей. PWA офлайн. Данные AP2 хранятся отдельно от AP1: ключи `ap2:` / `ap2-sync:`, IndexedDB `ap2-azubi`, кэши `ihk-ap2-*`.
- **`ihk-sim` не изменять никогда.** Даже `git status` там не запускать: он пишет в `.git`. Только копировать оттуда.
- **Экзамены.** Переписывать только вручную по картинкам страниц, без OCR и API. Хранить только в `privat/`. Материалы ZPA и u-form не публикуются.
- **Работа по сессиям.** Одна сессия — одна задача. Перед изменениями — план со списком файлов. Изменение структуры или удаление — только после «ок». Новые идеи — в `IDEEN.md`.
- **Менять минимально.** Работающие модули целиком не переписывать. Ответы и историю прогресса не удалять ради миграций.
- PIN — только блокировка экрана на устройстве, не защита опубликованных файлов.

## Решения

| Дата | Решение | Почему |
|---|---|---|
| 02.10.2026 | AP2 — отдельное приложение `ap2-sim`, `ihk-sim` остаётся как есть | AP1 хорошо работает, его нельзя ломать |
| 02.10.2026 | Экзамены переписываются вручную по картинкам | точность текста, кода и таблиц |
| 02.10.2026 | Оригинальные экзамены только в `privat/`, на телефон — файлом через «Paket laden» | авторские права; само приложение публикуется |
| 02.10.2026 | Прогресс и кэши AP2 отдельно от AP1 | оба приложения на одном сайте не должны мешать друг другу |
| 03.10.2026 | Цель — самоконтроль и слабые темы, не итоговая оценка; калькулятора оценки нет | так сказала Лена (записано в чате Codex) |
| 03.10.2026 | Порядок обучения: объяснение по-русски → термины → пример → практика с подсказками → самостоятельно → разбор → повтор в другой день | слабый немецкий и пробелы в основах; узнать ответ ≠ уметь решить |
| 03.10.2026 | У каждого экзамена указано, откуда решение: ZPA, u-form или собственное | неофициальное решение нельзя выдавать за ключ ZPA |
| 03.10.2026 | Автопроверка только там, где она надёжна (числа, SQL на учебной базе); остальное — самопроверка по критериям | совпадение слов ≠ правильный смысл |
| 03.10.2026 | Если работу оборвал лимит, агент продолжает ту же задачу по запланированному продолжению в этом же чате | работа не теряется |
| 04.10.2026 | Работаем по сессиям через `PROJEKT.md` и `IDEEN.md` | один понятный порядок вместо разрозненных планов |
| 10.10.2026 | Занятие можно отметить «разобранным» и без самопроверки | «разобрано» значит, что занятие пройдено; умение подтверждают самопроверка и практика |
| 10.10.2026 | Проект (50 % оценки) — третий этап, июнь 2027; до экзамена в апреле не трогаем | сначала письменный экзамен 28.04.2027 |
| 10.10.2026 | Код ученицы выполняет собственный маленький исполнитель (без `eval`), только язык в стиле экзамена | безопасно и честно проверяется на тестах |
| 10.10.2026 | Фото ответов хранятся только на устройстве (IndexedDB `ap2-fotos`) и не входят в резервную копию | размер файла копии; это сказано рядом с кнопкой |
| 10.10.2026 | Тексты настоящих GA в тренажёре операторов берутся только из личного пакета во время работы и нигде не сохраняются | авторские права |
| 10.10.2026 | Самооценка по пунктам: пункты составлены по решению; официальная разбивка в «So wird bewertet» главнее | честность оценки |
| 10.10.2026 | «Что тренировать» опирается на частоту тем в 20 GA и на твои попытки. Порядок пробных экзаменов: новые с решениями ZPA → u-form → собственные решения | честный ориентир без прогноза оценки; сначала экзамены с надёжными решениями |

## Проверка (после каждой задачи)

1. `node tests/alle.js` — 0 ошибок. Отложенные тесты AP1 не считаются.
2. Если менялись экзамены: `python3 tools/paket_bauen.py --pruefe privat/quellen/<id>.json` → OK, потом полная сборка `python3 tools/paket_bauen.py`. Напомнить Лене загрузить новый пакет на телефоне («Paket laden»).
3. Браузер, ширина 390 px: изменённый экран без горизонтального скролла, всё нажимается.
4. Один сценарий целиком: ответ → проверка → перезагрузка → ответ и прогресс на месте.
5. Консоль браузера без ошибок.
6. Если появился новый JS/CSS: файл есть в списке кэша `sw.js` и версия кэша поднята (`tests/pwa-shell_test.py`).
7. После перезагрузки без сети изменённый раздел открывается.
8. `ihk-sim` не изменён: сравнить время изменения файлов, git там не запускать.
9. Написать Лене, что прокликать на телефоне.
