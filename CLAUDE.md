# ap2-sim — для Claude

Начало каждой сессии: прочитать `PROJEKT.md` и `IDEEN.md`.
- `PROJEKT.md`: что это за приложение, структура, правила, решения, чек-лист проверки, состояние.
- `IDEEN.md`: задачи по приоритету. Для облака — раздел «Очередь для облака».

Порядок работы — как в правилах PROJEKT.md:
- одна сессия — одна задача;
- перед изменениями — план со списком файлов;
- изменение структуры или удаление — только после «ок» Лены;
- новые идеи — в IDEEN.md;
- в конце обновить PROJEKT.md и IDEEN.md, написать Лене 3–5 строк и предложить текст коммита.

Также действуют `AGENTS.md` (правило продолжения после лимитов, разделение работы с Codex) и `STATUS-EXAMENS.md` (оригинальные экзамены).

Коротко:
- `ihk-sim` не менять никогда (даже `git status` там не запускать).
- Экзамены — только ручное переписывание по картинкам страниц, только в `privat/`.
- Сначала мобильный экран (390 px).
- Ответы Лене — по-русски и коротко.
