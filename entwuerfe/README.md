1. Скопировать файлы на их место в проекте (поверх старых, если файл уже есть).
2. Доделать то, что перечислено ниже.
3. Подключить: `index.html`, `sw.js` (список файлов + новая VERSION), плитка в `gen/start.js`, экран в `gen/zurueck.js` (`SCHIRME`, `HOEHER`, `NAMEN`).
4. Прогнать `node tests/alle.js` и проверить в браузере на 390 px.
5. Удалить папку черновика.
