## katalog/ — чек-лист «Prüfungskatalog AP2» (2. Auflage 2024, действует с лета 2025)

**Файлы:**
- `gen/katalog-ap2-daten.js` — все пункты каталога AP2: AP2-01, AP2-02 (Anwendungsentwicklung), WiSo и приложение. Поля: `id`, `nr` («02.04.18»), `s`, `bereich`, `gruppe`, `titel` (своя короткая немецкая формулировка), `ru`, `stichworte`, `neu`, `pruefung` (GA1/GA2/WiSo), `trainieren` (до 4 ссылок в приложение), `hinweis`, `luecke`;
- `gen/katalog-ap2.js` — экран `scKatalog2`, `GENKATALOG2.oeffnen(filter?)`, ключ `ap2:katalog2` (своя отметка «знаю / повторить / не знаю»).

Данные помощник сверял постранично с картинками каталога. Сами картинки есть только у Лены локально, не в репозитории. Поэтому повторная сверка содержания — только локально (Cowork), не в облаке. Тексты — свои короткие формулировки, не копия каталога: проверено автоматически, совпадений длиннее 40 знаков нет, кроме общих терминов.

**Экран:**
- вверху: сколько пунктов, сколько с тренировкой, сколько «знаю», сколько новых;
- фильтры: Все / Новое 2025 / Не начато / Есть ошибки / GA1 / GA2 / WiSo; поиск по немецким и русским словам;
- пункт: номер, название, ключевые слова (свёрнуто), «neu 2025», мой статус (`GENLERNSTAND.summary()`, `GENLERNWEG.stand().done`), до 3–4 кнопок «тренировать», своя отметка;
- пункты без материала честно помечены — это список пробелов.
