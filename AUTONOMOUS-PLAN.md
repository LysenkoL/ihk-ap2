# Самостоятельная доработка AP2 — план

Дата: 02.10.2026. Основание: прямое поручение пользователя работать без его участия и возобновляться после лимитов. Подробный аудит: AUDIT-AP2-2026-10-02.md. Правила: AGENTS.md. Статус: AUTONOMOUS-STATUS.md.

## Продуктовый замысел

Цель — проверяемо полезный тренажёр для ученицы с недостаточным немецким и фундаментом ИТ. Сохранить статическое приложение и его удачные инструменты. Уменьшить число решений, которые ученица должна принять перед занятием: один понятный следующий шаг, небольшие занятия, объяснение терминов в контексте, постепенный переход к самостоятельной работе.

Выбран постепенный путь: исправить достоверность → построить маршрут поверх существующего материала → добавить практику недостающих навыков → соединить реальные экзамены и диагностику. Полное переписывание UI/стека и наращивание теории без практики отклонены как не приносящие первоочередной учебной пользы.

Критерии результата: не теряются ответы; баллы математически корректны; неверные ответы не показываются как гарантированно правильные; пользователь видит реальные пробелы и следующий шаг; новые навыки проверяются самостоятельными заданиями; русская помощь убывает по мере освоения; важные маршруты работают на телефоне и без обязательного сервера.

## Процесс каждой существенной задачи

Проверить гипотезу/исходный дефект → добавить содержательный падающий тест → минимальная реализация → зелёный тест → релевантный общий набор → обзор изменений → запись статуса. Параллельные исполнители владеют разными файлами. Общие `index.html`, `sw.js`, главная страница и статус редактируются координатором.

## Особые случаи при обзоре

Пользователь уже накопил старые оценки; импорт повторён дважды; два устройства решили разные задания одной работы; подсказка прочитана до ответа; вкладка скрыта во время строгого экзамена; несколько допустимых критических путей; данных нет; официальный ключ отсутствует; новые ресурсы не попали в PWA-кэш. Каждый относится к этапу, владеющему соответствующей функцией.
